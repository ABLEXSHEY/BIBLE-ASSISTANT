# Bible Assistant Mockup Demo

A React single-page application that recreates nine high-fidelity UI mockups for an AI-powered Bible study companion. Each screen mirrors the provided visual references and demonstrates navigation between onboarding, study, counseling, premium, library, and settings experiences.

## Getting Started

```bash
npm install
npm run dev
```

Vite will start a development server at `http://localhost:5173`.

## Available Screens

- **Home** – Verse highlight, quick search, and navigation cards.
- **Onboarding** – Three-step onboarding flow introducing the assistant.
- **Counseling & Care** – Chat-style conversation layout.
- **Passage Study** – Scripture passage with contextual sections.
- **Library** – Saved studies list with category tabs.
- **Go Premium** – Pricing comparison cards and trial CTA.
- **Settings** – Appearance, notifications, and support options.

Use the top navigation pills to jump between mockups.
